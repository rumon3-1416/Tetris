## Tetris
[https://rumon3-1416.github.io/Tetris/](https://rumon3-1416.github.io/Tetris/)

This is a simple Tetris game built using HTML, CSS, and JavaScript. The game allows players to control falling blocks and arrange them to complete lines. When a line is fully filled, it disappears, and the player's score increases by one. The game continues until the blocks stack up and the screen is filled.

## Features

- Playable with keyboard controls to move and rotate blocks.
- Blocks automatically fall and accelerate over time.
- Lines are cleared as they are filled, increasing the score.
- Score is displayed and updated in real-time.

## Technologies Used
- HTML
- CSS
- Javascript
